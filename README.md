# OncoPath Advisory Group Site Prototype

Local static prototype for the OncoPath Advisory Group landing page.

## Files

- `index.html` - umbrella OncoPath Advisory Group homepage.
- `fellows.html` - fellow-facing Fellows Exchange registration page.
- `residents.html` - resident physician pathway / interest page.
- `consulting.html` - medical oncology and hematology consulting services page.
- `sponsor.html` - separate sponsor and career-partner inquiry overview page.
- `styles.css` - responsive visual system and layout.
- `script.js` - mobile navigation and prototype contact-form behavior.
- `assets/oncopath-hero.png` - generated hero image for the landing page.
- `claude-design-brief.md` - prompt/brief for Claude Design or another design tool.
- `docs/VISION_AND_MVP.md` - business vision, MVP target, long-term roadmap, and near-term decisions.

## Launch Notes

This prototype does not collect data or submit inquiries. Before public launch, connect forms to the selected platform, review copy with healthcare compliance counsel, and confirm whether OncoPath will use Framer, Webflow, Wix, Luma, Eventbrite, Airtable, or another stack.

No CME claim should be made unless an accredited CME partner is in place.
